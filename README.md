# 도파민 멈춰!

Chrome **Manifest V3** 확장 프로그램입니다. 유튜브 등 지정 사이트에 대해 **시간대 차단**과 **일일 사용 한도**를 걸고, 규칙에 따라 화면을 차단합니다. 데이터는 **기기 안(로컬)에만** 저장하며 외부 서버로 보내지 않습니다.

**버전:** 0.1.0 (개발 중)

---

## 주요 기능

- **시간대 차단** — 요일·시간 범위별 차단 규칙
- **일일 사용 한도** — 하루(또는 설정한 리셋 시각) 기준 누적 사용 시간 제한
- **트리거 조합** — OR / AND 로 조건 조합
- **차단 사이트 목록** — 기본 `youtube.com`, `youtu.be` 외 도메인 추가(추가 시 호스트 권한 요청)
- **설정 저장 후 쿨다운** — 의미 있는 설정 변경은 저장 시점 기준 **24시간** 동안 제한
- **차단 중 해제 UI 없음** — 조건이 풀릴 때까지 확장 UI로 즉석 해제하지 않음(크롬에서 확장 끄기는 여전히 가능)
- **팝업** — 사용량·차단 상태·설정 잠금 안내
- **차단 화면** — `blocked.html` 또는 페이지 위 **콘텐츠 스크립트 오버레이**로 동일 안내

자세한 제품 방향은 [`docs/PRODUCT_PLAN.md`](docs/PRODUCT_PLAN.md)를 참고하세요.

---

## 설치 방법 (개발 / 압축 해제)

1. 이 저장소를 클론합니다.
2. Chrome에서 `chrome://extensions` 를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** → 이 프로젝트 폴더를 선택합니다.
5. 옵션 페이지에서 규칙을 저장합니다.

아이콘을 다시 만들 때(선택):

```bash
node scripts/generate_icons.js
```

---

## 아이콘 크기

`manifest.json` 기준 **16×16**, **48×48**, **128×128** PNG (`icons/icon*.png`)를 사용합니다.

## 권한 요약

| 권한 | 용도 |
|------|------|
| `storage` | 설정·사용량·차단 상태 로컬 저장 |
| `alarms` | 주기적 차단 상태 갱신 |
| `declarativeNetRequest` (+ Feedback) | 필요 시 네트워크 규칙으로 리다이렉트 |
| `scripting` | 동적 규칙·스크립트와 연동 |
| `tabs` | 탭·상태 연동 |
| 호스트 (`youtube.com`, `youtu.be`) | 콘텐츠 스크립트·차단 대상 |
| `optional_host_permissions` (`<all_urls>`) | 사용자가 추가한 차단 도메인 |

---

## 개인정보 / 데이터 수집

- **원격 분석·서버 전송·외부 API 호출은 없습니다.**
- 모든 관련 데이터는 **`chrome.storage.local`** 에만 보관됩니다.

---

## 프로젝트 구조(요약)

| 경로 | 설명 |
|------|------|
| `service_worker.js` | 백그라운드, 집계·차단 평가·알람 |
| `content_script.js` | 유튜브 등에서 사용 시간 보고·차단 오버레이 |
| `options.*` | 설정 페이지 |
| `popup.*` | 툴바 팝업 |
| `blocked.html` / `blocked.js` | 차단 전용 페이지 |
| `shared/` | 공용 상수·차단 로직 |
| `rules/` | DNR 정적 규칙 JSON |
